# User Manual & Help Documentation Plan

This document outlines the planned structure and content for the end-user documentation, Help Center, and video tutorials.

## 1. Student Guide

Target Audience: End-users taking exams, reviewing results, and practicing.

**Planned Sections:**
*   **Getting Started**: Logging in, setting up your profile, understanding the dashboard.
*   **Taking an Exam**: Navigating the exam interface, using the scratchpad, flagging questions, submitting the exam, handling disconnects.
*   **Viewing Results**: Interpreting the score report, reviewing incorrect answers, understanding percentiles.
*   **Understanding Your Proficiency Map**: How to read the subject/topic mastery charts.
*   **Using Practice Papers**: Generating custom practice sessions based on weak areas.
*   **AI Interview Guide**: How to prepare your mic/camera, understanding the AI persona, reviewing interview transcripts.
*   **Managing Subscription**: Upgrading, checking quotas, updating billing info.
*   **FAQ & Troubleshooting**: Common login issues, browser requirements.

## 2. Teacher Guide

Target Audience: Educators creating content, building exams, and monitoring students.

**Planned Sections:**
*   **Creating Courses & Syllabus**: Defining the curriculum tree (Subjects -> Topics -> Subtopics).
*   **Managing the Question Bank**: Creating questions manually, bulk importing via CSV, managing difficulty levels and tags.
*   **Reviewing AI Questions**: How to use the AI Generator, reviewing, editing, and approving AI drafts.
*   **Creating Exam Patterns**: Setting rules (number of sections, question distribution, marking schemes, negative marking).
*   **Generating & Scheduling Exams**: Compiling an exam paper from a pattern, scheduling it for a cohort.
*   **Viewing Class Reports**: Analyzing cohort performance, identifying common weak topics.
*   **Using Preview Mode**: Testing exams and the platform exactly as a student would see it.

## 3. Admin Guide

Target Audience: System administrators managing the platform.

**Planned Sections:**
*   **User Management**: Onboarding staff/teachers, bulk student import, handling password resets.
*   **Role Management**: Assigning granular permissions via RBAC.
*   **System Configuration**: Global settings, timezone config, institutional branding.
*   **Audit Logs**: Tracking who did what and when.
*   **Subscription Management**: Creating and modifying pricing plans, managing institutional licenses.
*   **AI Configuration**: Selecting AI providers, setting token limits, monitoring AI costs.
*   **Platform Reports**: High-level system usage, revenue tracking, storage metrics.

## 4. Help Center Structure

The online Help Center will be built using a tool like Zendesk, Intercom, or Docusaurus.

*   **Search-First Design**: Prominent search bar powered by Algolia or similar.
*   **Categories**: Segregated by user role (Student, Teacher, Admin).
*   **Article Templates**: Standardized format including: Title, Prerequisites, Step-by-Step Instructions (with screenshots), and "See Also" links.
*   **Feedback Mechanism**: "Was this article helpful? (Thumbs Up/Down)" on every page to identify documentation gaps.

## 5. Video Tutorial Plan

Key workflows to record (screencasts with voiceover):
1.  **Student Overview**: 3-minute tour of the student dashboard and taking an exam.
2.  **Teacher Quickstart**: How to create your first question and exam.
3.  **The AI Generator in Action**: Demonstrating how teachers can save time generating question banks.
4.  **Understanding Analytics**: A deep dive into interpreting student and class performance reports.
5.  **Setting up Complex Exam Patterns**: Tutorial on advanced scoring and section rules.
