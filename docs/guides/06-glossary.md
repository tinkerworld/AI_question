# Glossary & Domain Terminology

This glossary defines standard terminology used across the Adaptive Examination & AI Learning Platform. Using consistent terminology is crucial for clear communication and codebase alignment.

- **Adaptive Practice**: A practice mode where the system adjusts question difficulty based on the student's ongoing performance.
- **AI Credit**: A unit of currency used to meter and limit a user's usage of AI features (e.g., subjective evaluation, hints).
- **AI Gateway**: The central, provider-agnostic service (Python FastAPI) that routes AI requests to various LLM providers (OpenAI, Anthropic, Ollama).
- **Answer Key**: The definitive set of correct answers and evaluation rubrics for an exam.
- **Attempt**: A single instance of a user taking an exam, mock test, or practice session.
- **Audit Log**: An immutable, chronological record of security-relevant events and administrative actions in the system.
- **Concept**: A specific, granular learning node within a Subject or Syllabus.
- **Course**: A structured learning program comprising a syllabus, exams, practice material, and enrolled students.
- **Difficulty Distribution**: The defined ratio of Easy, Medium, and Hard questions in an Exam Pattern.
- **Draft**: The state of a Question or Exam that is currently being authored and is not yet visible to students.
- **Enrollment**: The association mapping a Student to a specific Course.
- **Entitlement**: A specific right granted to a user, typically tied to a Subscription Plan (e.g., "Can take 5 Mock Tests").
- **Entitlement Engine**: The system module responsible for checking if a user has the requisite entitlements to perform an action.
- **Evaluation**: The process (manual or AI-driven) of grading a submitted Attempt.
- **Exam**: A scheduled, formal assessment comprising multiple sections and questions.
- **Exam Archive**: Read-only storage of past exams for historical reference.
- **Exam Attempt**: The record of a student's interaction with an Exam, including their submitted answers and timing data.
- **Exam Pattern**: The structural blueprint for an exam (e.g., Section A has 10 MCQs, Section B has 5 Short Answers).
- **Exam Section**: A logical grouping of questions within an exam, often with its own specific rules or timer.
- **Fill-in-Blank**: A question type requiring the user to provide a specific missing word or phrase.
- **Follow-up Question**: A dynamic question generated by the AI based on a student's previous answer, used in Interview Assessments.
- **Impersonation**: A feature allowing Main Admins to securely log in as another user for troubleshooting, heavily audited.
- **Interview Assessment**: An interactive, conversational assessment mode utilizing AI for real-time questioning.
- **Interview Session**: A single, contiguous interaction in an Interview Assessment.
- **Interview Template**: A predefined configuration (role, subject, strictness) for an AI Interview.
- **Learning Objective**: The targeted outcome or skill that a specific question or concept aims to measure.
- **Main Admin**: The highest privilege user role, possessing full access to all system modules and settings.
- **Mastery**: A calculated metric representing a student's proficiency in a specific Concept or Subject.
- **Mastery Confirmation**: The point at which the system establishes high confidence in a student's Mastery level.
- **MCQ (Multiple Choice Question)**: A question type with multiple options and one or more correct answers.
- **Mock Test**: A practice exam designed to simulate the environment and pattern of a real exam.
- **Modular Monolith**: The architectural pattern of the Express backend, organized by domain modules rather than technical layers.
- **Negative Marking**: The deduction of points for an incorrect answer, defined at the Question or Section level.
- **Numerical Question**: A question type where the answer is a specific number or range.
- **Partial Marking**: Awarding partial credit for an answer that is incomplete but partially correct (common in Subjective or multi-select MCQ).
- **Permission**: A granular, string-based access right (e.g., `users.read`, `exams.create`).
- **Practice Paper**: An unscored, self-paced assessment generated for practice purposes.
- **Preview Student**: A special, transient profile used by Teachers/Admins to experience the platform exactly as a student would.
- **Proficiency**: A qualitative label (e.g., Novice, Competent, Expert) derived from a quantitative Mastery score.
- **Provider Adapter**: The design pattern used in the AI Gateway to standardize interfaces across different LLM providers.
- **Published**: The state of a Question or Exam that makes it live and accessible to assigned users.
- **Question Bank**: The central repository of all questions, organized by Subject, Tag, and Concept.
- **Question Lifecycle**: The state machine of a question: Draft -> Reviewed -> Published -> Archived.
- **Question Snapshot**: An immutable copy of a question taken at the time an exam is published, ensuring future edits don't alter past exams.
- **Question Type**: The format of a question (e.g., MCQ, True/False, Subjective).
- **Question Version**: An iteration of a question; edits to published questions create new versions.
- **RBAC (Role-Based Access Control)**: The authorization model mapping users to Roles, and Roles to Permissions.
- **Refresh Token**: A long-lived token (7d) used to securely obtain new short-lived access tokens.
- **Role**: A named collection of permissions (e.g., Teacher, Sub-Admin).
- **Rubric**: The defined criteria used by human evaluators or AI to grade subjective questions.
- **Section Rule**: Constraints applied to an Exam Section (e.g., "Answer any 5 out of 10 questions").
- **Short Answer**: A subjective question type expecting a concise text response.
- **Skill Focus**: The specific cognitive skill a question targets (e.g., Recall, Application, Analysis).
- **Snapshot**: A point-in-time copy of data, typically used for exams to freeze questions.
- **STT (Speech-to-Text)**: Audio transcription functionality used in Interview Assessments.
- **Sub-Admin**: A delegated administrative role with a subset of permissions granted by a Main Admin.
- **Subject**: A high-level domain of study (e.g., Physics, Mathematics).
- **Subjective Question**: A question type requiring a free-text, detailed response.
- **Subscription Plan**: A predefined tier granting specific entitlements and AI Credits to a user or institution.
- **Syllabus Node**: A single entry (Chapter, Topic, Concept) within a Syllabus Tree.
- **Syllabus Tree**: The hierarchical structure mapping Subjects to Chapters, Topics, and Concepts.
- **TTS (Text-to-Speech)**: Audio generation functionality used in Interview Assessments to read questions aloud.
- **Tag**: A flexible metadata label applied to questions for easy filtering and dynamic exam generation.
- **Teacher**: A role responsible for authoring content, creating exams, and monitoring student progress.
- **Timer**: The component enforcing time limits on Exams, Sections, or Individual Questions.
- **Topic Distribution**: The defined spread of topics required in a generated Exam Pattern.
- **True/False**: A boolean question type.
- **Weakness Pool**: A dynamic set of concepts where a student's Mastery is low, used to drive Adaptive Practice.
