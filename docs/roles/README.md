# Developer & Team Role Guidelines — Master Index

## Purpose

This directory contains **individual guideline documents for every team role** on the Adaptive Examination & AI Learning Platform project. Each document is a standalone reference covering:

- **Role Overview** — What the role does on this project
- **Core Responsibilities** — Primary duties
- **Work Boundaries** — What they OWN vs COLLABORATE vs OUT OF SCOPE
- **Phase-by-Phase Goals** — Specific deliverables for each of the 14 development phases
- **Key Guidelines** — Technical standards, collaboration model, tools & processes
- **Do's ✅** — Best practices and encouraged behaviors (15+ items)
- **Don'ts ❌** — Anti-patterns and prohibited behaviors (15+ items)
- **Quality Gates** — Checkpoints before work is considered done
- **Escalation Path** — When and how to escalate
- **KPIs & Metrics** — How performance is measured

## How to Use These Documents

### For Hiring
Reference these documents to write job descriptions with exact responsibilities and expectations.

### For Onboarding
New team members read their role document + cross-referenced role documents to understand boundaries and collaboration points.

### For Performance Reviews
Use KPIs and Quality Gates from the role document as evaluation criteria.

### For Sprint Planning
Use Phase-by-Phase Goals to determine what each role should deliver in the current sprint.

### For Conflict Resolution
Reference Work Boundaries table to clarify ownership when responsibilities overlap.
