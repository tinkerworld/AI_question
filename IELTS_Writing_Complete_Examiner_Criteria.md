# IELTS Writing Examination Criteria – Complete Checking Points

## Overview

IELTS Writing is assessed using **four official marking criteria**. Each criterion contributes equally to the score for an individual writing task.

For IELTS Writing:

- **Task 1** contributes approximately one-third of the overall Writing score.
- **Task 2** contributes approximately two-thirds of the overall Writing score.
- Each individual task is assessed using four major criteria.
- The detailed checks listed in this document should be used as evidence for assigning a score under the four official criteria.

---

# 1. Task Achievement / Task Response

## Official Naming

- **Academic Task 1:** Task Achievement
- **General Training Task 1:** Task Achievement
- **Task 2:** Task Response

This criterion evaluates whether the candidate has understood the task and answered it appropriately.

---

## 1.1 Academic Writing Task 1 – Checking Points

For graphs, charts, tables, maps, diagrams, and processes, check whether the candidate:

### Understanding of the Task

- Understands what the visual information represents.
- Identifies the correct subject of the graph, chart, table, map, or process.
- Does not misunderstand the units, dates, categories, locations, or stages.
- Does not introduce information that is not shown.

### Overview

- Provides a clear overview.
- Identifies the most important overall trends.
- Identifies major similarities or differences.
- Identifies important changes.
- Avoids including unnecessary detail in the overview.
- Keeps the overview separate from minor details where appropriate.

### Key Features

- Selects the most important features.
- Does not attempt to describe every individual number.
- Identifies major increases.
- Identifies major decreases.
- Identifies stable trends.
- Identifies fluctuations.
- Identifies highest values.
- Identifies lowest values.
- Identifies major turning points.
- Identifies significant differences.
- Identifies similarities.
- Identifies unusual or exceptional data where relevant.

### Comparisons

- Makes meaningful comparisons.
- Compares categories rather than describing them separately.
- Compares changes over time.
- Compares highest and lowest values.
- Compares similar groups.
- Compares contrasting groups.
- Avoids unnecessary comparisons.

### Data Accuracy

- Reports figures correctly.
- Uses percentages correctly.
- Uses dates correctly.
- Uses units correctly.
- Does not reverse increases and decreases.
- Does not exaggerate changes.
- Does not invent values.
- Does not misread the graph.

### Process Diagrams

For process questions, check whether the candidate:

- Identifies the starting point.
- Identifies the ending point.
- Describes the stages in the correct order.
- Includes important stages.
- Does not add imaginary stages.
- Explains cyclical processes correctly.
- Uses suitable sequencing language.
- Uses passive structures appropriately when relevant.

### Maps

For map questions, check whether the candidate:

- Identifies major changes.
- Correctly describes locations.
- Identifies additions.
- Identifies removals.
- Identifies replacements.
- Identifies expansions.
- Identifies reductions.
- Identifies changes in land use.
- Makes before-and-after comparisons.
- Uses appropriate location language.

### Relevance

- Avoids personal opinions unless specifically required.
- Avoids explaining causes unless the task requires it.
- Does not speculate unnecessarily.
- Focuses on the information presented.

### Minimum Length

- Writes at least **150 words**.
- Avoids excessive memorized or irrelevant material.

---

## 1.2 General Training Task 1 – Checking Points

For letters, check whether the candidate:

### Purpose

- Clearly states the purpose of the letter.
- Maintains that purpose throughout the response.

### Bullet Points

- Addresses all required bullet points.
- Develops each bullet point sufficiently.
- Does not ignore important instructions.
- Gives enough supporting information.

### Tone

- Uses the correct level of formality.
- Uses formal language when writing to an unknown person or authority.
- Uses semi-formal language when appropriate.
- Uses informal language appropriately for friends or family.
- Maintains a consistent tone.

### Opening and Closing

- Uses an appropriate greeting.
- Uses an appropriate introduction.
- Ends the letter appropriately.
- Uses a suitable sign-off.

### Content

- Includes relevant information.
- Gives necessary explanations.
- Gives appropriate requests.
- Gives appropriate apologies when required.
- Gives appropriate complaints where required.
- Gives relevant suggestions.
- Avoids irrelevant details.

### Minimum Length

- Writes at least **150 words**.

---

## 1.3 Writing Task 2 – Checking Points

Task 2 requires a developed essay response.

### Understanding the Question

Check whether the candidate:

- Correctly identifies the topic.
- Correctly identifies the question type.
- Understands exactly what is being asked.
- Does not answer a different question.

### Question Types

The examiner should recognize whether the task is:

- Opinion essay.
- Agree/disagree essay.
- Discussion essay.
- Advantages/disadvantages essay.
- Problems/solutions essay.
- Causes/effects essay.
- Two-part question.
- Mixed question type.

### Complete Task Coverage

Check whether the candidate:

- Answers every part of the question.
- Does not ignore a second or third instruction.
- Gives enough attention to each required part.

### Position / Opinion

- States a clear position where required.
- Maintains the position consistently.
- Does not contradict the position later.
- Makes the position clear in the introduction or early in the essay.
- Reinforces the position in the conclusion.

### Main Ideas

- Presents clear main ideas.
- Uses ideas that are relevant to the question.
- Avoids vague or unrelated ideas.
- Keeps each paragraph focused.

### Development of Ideas

- Explains ideas.
- Gives reasons.
- Gives examples where useful.
- Shows how examples support the argument.
- Avoids unsupported claims.
- Develops ideas sufficiently.
- Avoids listing ideas without explanation.

### Relevance

- Stays on topic.
- Avoids unnecessary stories.
- Avoids irrelevant examples.
- Avoids memorized paragraphs that do not fit the question.

### Conclusion

- Includes an appropriate conclusion.
- Summarizes the main position.
- Does not introduce completely new arguments.
- Remains consistent with the body of the essay.

### Minimum Length

- Writes at least **250 words**.

---

# 2. Coherence and Cohesion

This criterion evaluates how logically the writing is organized and how effectively ideas are connected.

---

## 2.1 Overall Organization

Check whether the candidate:

- Uses a logical structure.
- Organizes information clearly.
- Presents ideas in a sensible order.
- Has a clear introduction where appropriate.
- Has clear body paragraphs.
- Has a suitable conclusion where appropriate.
- Avoids jumping randomly between ideas.

---

## 2.2 Paragraphing

Check:

- Whether paragraphs are used appropriately.
- Whether each paragraph has a central idea.
- Whether paragraph boundaries make sense.
- Whether paragraphs are not excessively long.
- Whether paragraphs are not unnecessarily short.
- Whether the essay is not written as one large block.
- Whether paragraphs progress logically.

---

## 2.3 Topic Sentences

Check whether:

- Paragraphs have clear controlling ideas.
- Topic sentences introduce the paragraph effectively.
- Supporting sentences relate to the topic sentence.

---

## 2.4 Logical Progression

Check whether:

- One idea naturally leads to the next.
- The argument develops step by step.
- Earlier ideas support later ideas.
- The reader can easily follow the reasoning.
- There are no sudden unexplained topic changes.

---

## 2.5 Cohesive Devices

Evaluate the appropriate use of linking words and phrases such as:

- however
- therefore
- furthermore
- moreover
- consequently
- although
- because
- while
- whereas
- nevertheless
- similarly
- in contrast
- on the other hand
- as a result
- for example
- for instance
- in addition

### Check for Problems

- Overuse of linking words.
- Repetitive connectors.
- Mechanical linking.
- Incorrect connectors.
- Unnecessary connectors.
- Use of connectors that do not match the logical relationship.

Example of poor cohesion:

> Firstly... Secondly... Moreover... Furthermore... However... Therefore...

Using many connectors does not automatically improve the score.

---

## 2.6 Referencing

Check correct use of:

- this
- these
- those
- it
- they
- such
- which
- former
- latter

Example:

> Renewable energy became cheaper. **This development** encouraged greater adoption.

The reference should clearly point to the intended earlier idea.

---

## 2.7 Repetition

Check whether:

- Important words are unnecessarily repeated.
- Pronouns or referencing are used appropriately.
- Synonyms are used naturally.
- Repetition is avoided without forcing unnatural vocabulary.

---

## 2.8 Sentence-to-Sentence Flow

Check whether:

- Sentences connect naturally.
- Ideas are not isolated.
- Each sentence contributes to the paragraph.
- Transitions between sentences are smooth.

---

# 3. Lexical Resource

Lexical Resource refers to the range, accuracy, flexibility, and appropriateness of vocabulary.

---

## 3.1 Vocabulary Range

Check:

- Variety of vocabulary.
- Topic-specific vocabulary.
- Ability to express similar ideas in different ways.
- Avoidance of excessive repetition.
- Use of both common and less common vocabulary where appropriate.

---

## 3.2 Vocabulary Accuracy

Check:

- Correct meaning.
- Correct context.
- Correct word choice.
- Correct level of formality.
- Correct grammatical form.

---

## 3.3 Precision

Check whether words are:

- Specific.
- Accurate.
- Appropriate to the intended meaning.
- Not unnecessarily vague.

---

## 3.4 Collocations

Check natural word combinations.

Correct:

- make a decision
- heavy traffic
- strong argument
- economic growth
- significant increase

Incorrect or unnatural:

- do a decision
- strong traffic
- powerful rain

---

## 3.5 Word Formation

Check correct use of:

- nouns
- verbs
- adjectives
- adverbs
- prefixes
- suffixes
- word families

Example:

- develop
- development
- developed
- developing

Check errors such as:

- incorrect noun forms
- incorrect adjective forms
- incorrect adverb forms

---

## 3.6 Paraphrasing

Check whether the candidate can:

- Restate the question naturally.
- Express an idea using different wording.
- Avoid copying the prompt excessively.
- Avoid changing the original meaning.

Example:

Original:

> Many people believe public transportation should be free.

Possible paraphrase:

> It is often argued that public transport should be provided without charge.

Paraphrasing should remain natural.

---

## 3.7 Register

Check whether vocabulary matches the situation.

Academic writing generally requires neutral or formal language.

Examples:

More appropriate:

- children
- significant
- increase
- decrease
- expenditure
- employment

Less appropriate in formal academic writing:

- kids
- huge crazy increase
- loads of money

---

## 3.8 Spelling

Check:

- Correct spelling.
- Repeated spelling errors.
- Whether spelling errors affect understanding.

Examples commonly misspelled:

- government
- environment
- necessary
- opportunity
- development

---

## 3.9 Unnatural Vocabulary

Detect:

- Forced synonyms.
- Incorrect "advanced" words.
- Memorized phrases used incorrectly.
- Words that technically exist but sound unnatural in context.

The system should not reward uncommon words merely because they are difficult.

---

# 4. Grammatical Range and Accuracy

This criterion evaluates both the variety of grammatical structures and how accurately they are used.

---

# 4.1 Grammatical Range

Check whether the candidate uses a variety of sentence types.

## Simple Sentences

Example:

> Technology affects education.

## Compound Sentences

Example:

> Technology affects education, and schools increasingly depend on digital tools.

## Complex Sentences

Example:

> Although technology improves access to information, excessive dependence on it may create other problems.

The system should reward **controlled variety**, not complexity for its own sake.

---

## 4.2 Sentence Structures to Check

Evaluate the appropriate use of:

- Simple sentences.
- Compound sentences.
- Complex sentences.
- Subordinate clauses.
- Relative clauses.
- Conditional sentences.
- Passive structures.
- Comparative structures.
- Superlative structures.
- Participial clauses.
- Modal verbs.
- Different sentence openings.

---

## 4.3 Grammar Accuracy

Check the following areas.

### Subject–Verb Agreement

Incorrect:

> People is using technology.

Correct:

> People are using technology.

### Verb Tenses

Check:

- Present simple.
- Present continuous.
- Past simple.
- Past continuous.
- Present perfect.
- Past perfect.
- Future structures.

### Articles

Check:

- a
- an
- the
- zero article

### Prepositions

Check correct use of:

- in
- on
- at
- by
- for
- from
- with
- to

### Pronouns

Check:

- Correct pronoun reference.
- Singular/plural consistency.
- Subject/object pronouns.
- Possessive pronouns.

### Singular and Plural Forms

Check:

- Noun number.
- Verb agreement.
- Irregular plurals.

### Countable and Uncountable Nouns

Examples:

- information — uncountable
- advice — uncountable
- people — plural
- equipment — generally uncountable

### Auxiliary Verbs

Check correct use of:

- do
- does
- did
- have
- has
- had
- be forms

### Modal Verbs

Check:

- can
- could
- may
- might
- should
- must
- would

### Adjective / Adverb Usage

Check whether adjectives and adverbs are correctly formed and positioned.

### Comparatives

Check:

- higher than
- lower than
- more significant than
- less common than

### Superlatives

Check:

- the highest
- the lowest
- the most significant
- the least important

### Conditionals

Check accurate use of conditional structures.

### Passive Voice

Check whether passive structures are formed correctly and used appropriately.

### Relative Clauses

Check:

- who
- which
- that
- whose
- where

### Conjunctions

Check:

- and
- but
- because
- although
- while
- whereas
- since

### Word Order

Check correct English sentence order.

---

# 4.4 Sentence Errors

Detect:

## Sentence Fragments

Incomplete sentences that do not express a full idea.

## Run-on Sentences

Two or more independent clauses incorrectly joined.

## Comma Splices

Independent clauses joined only with a comma when stronger punctuation or conjunction is required.

---

# 4.5 Punctuation

Check:

- Full stops.
- Commas.
- Apostrophes.
- Colons.
- Semicolons.
- Question marks where applicable.
- Hyphens where appropriate.

---

# 4.6 Capitalization

Check:

- Beginning of sentences.
- Proper nouns.
- Countries.
- Cities.
- Organizations.
- Months.
- Days.
- Names.

---

# 4.7 Error Frequency

The evaluator should consider:

- Number of grammatical errors.
- Number of error-free sentences.
- Percentage of error-free sentences.
- Repeated patterns of error.
- Whether the same mistake occurs frequently.

---

# 4.8 Error Severity

Errors should not all be treated equally.

Suggested categories:

### Minor Error

The meaning remains completely clear.

### Moderate Error

The sentence is understandable but awkward or inaccurate.

### Major Error

The reader must work to understand the sentence.

### Critical Error

The error changes or seriously obscures the intended meaning.

# 6. Suggested Scoring Output

A writing evaluation system can produce results like:

```text

Coherence & Cohesion:           Band 7.0
Lexical Resource:               Band 6.5
Grammatical Range & Accuracy:   Band 6.0

Estimated Task Band:            6.5
```

---

# 7. Important Scoring Principle

Do **not** assign independent IELTS bands to every small check and simply average them.

For example, do not independently score:

- spelling
- punctuation
- vocabulary
- articles
- paragraphing
- examples
- tenses

and then calculate one simple average.

Instead:

1. Perform all detailed checks.
2. Collect evidence.
3. Use that evidence to decide the score for each of the **four official IELTS criteria**.
4. Calculate the task result from those four criteria.

---

# 8. Task Weighting

## Task 1

Task 1 contributes approximately **one-third** of the overall IELTS Writing score.

## Task 2

Task 2 contributes approximately **two-thirds** of the overall IELTS Writing score.

Therefore, weaknesses in Task 2 generally have a larger effect on the final Writing band.

---

# 9. Recommended AI Feedback Output

For each criterion, an AI evaluator should ideally return:

### Band

Example:

```text
Lexical Resource: 6.5
```

### Strengths

Example:

```text
- Good use of topic-specific vocabulary.
- Several natural collocations.
- Effective paraphrasing of the prompt.
```

### Problems

Example:

```text
- "do a decision" is an incorrect collocation.
- The word "important" is repeated too frequently.
- Several spelling errors appear in common academic vocabulary.
```

### Evidence

Quote or identify the exact sentence containing the problem.

### Correction

Provide a corrected version.

### Improvement Advice

Explain what the candidate needs to do to move to the next band.

# 10. Recommended Error Annotation Format

For an AI-based IELTS system, each detected issue can be stored like this:

```json
{
  "category": "Grammar",
  "subcategory": "Subject-Verb Agreement",
  "severity": "Moderate",
  "original": "People is using technology.",
  "correction": "People are using technology.",
  "explanation": "The plural subject 'people' requires the plural verb 'are'.",
  "criterion": "Grammatical Range and Accuracy"
}
```

Another example:

```json
{
  "category": "Vocabulary",
  "subcategory": "Collocation",
  "severity": "Moderate",
  "original": "People should do a decision.",
  "correction": "People should make a decision.",
  "explanation": "'Make a decision' is the natural English collocation.",
  "criterion": "Lexical Resource"
}
```

## Summary

A strong IELTS Writing evaluator should assess far more than grammar.

It should examine:

1. **Whether the candidate answered the question properly.**
2. **Whether ideas are logically organized and connected.**
3. **Whether vocabulary is accurate, varied, and natural.**
4. **Whether grammatical structures are varied and controlled.**
5. **How serious each error is.**
6. **Whether errors affect communication.**
7. **What specifically prevents the candidate from reaching the next band.**

These detailed checks should ultimately contribute to the four official IELTS Writing assessment criteria rather than operating as unrelated independent scores.
